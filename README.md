
# CoffeeLate


CoffeeLate es un proyecto frontend individual realizado durante el bootcamp de soy Henry
## 🛠 Tecnologias
Nextjs, React,Typescript, TailwindCss, Context, Formik Flowbite, sonner


## Iniciar Proyecto

Front
```bash
  cd front
  npm run dev
```

Back
```bash
  cd back
  npm start
```
